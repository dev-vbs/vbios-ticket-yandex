# Настройка S3 для тикетов

Актуальная инструкция: [Yandex Cloud и Object Storage](new-server/YANDEX-CLOUD-TICKETS.md).

Полная установка проекта: [README](../README.md). Основной Compose уже передаёт `TICKET_S3_ACCESS_KEY` и `TICKET_S3_SECRET_KEY` в core/spool. Для готовых GHCR-образов дополнительный override и пути исходников не нужны.

После изменения ключей выполните `docker compose up -d --force-recreate core spool` из `/opt/shm`. Обычный `restart` не обновляет переменные окружения. Бакет остаётся приватным.
