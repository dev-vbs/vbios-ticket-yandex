# SMS-уведомления через SMSC.ru

SMS и Web Push включаются отдельно на странице «Уведомления». SMS по умолчанию выключены. Для подключения нужен один номер в международном формате в профиле и согласие пользователя.

## Подключение

В `/opt/shm/.env` укажите настройки аккаунта SMSC.ru. Имя отправителя указывайте, если оно согласовано у провайдера.

```dotenv
SMSC_ENABLED=true
SMSC_LOGIN=ваш_логин
SMSC_PASSWORD=ваш_пароль_для_API
SMSC_SENDER=
```

В Docker Compose эти переменные передаются в `core` и `spool`. Если у вас собственный Compose-файл, добавьте те же четыре переменные в `environment` обоих сервисов. После публикации образов выполните:

```bash
cd /opt/shm
docker compose pull core spool client &&
docker compose up -d --no-deps --force-recreate core spool client
```

Откройте «Уведомления» в кабинете, включите «Получать SMS» и проверьте ответ на тестовое обращение. SMS об ответах оператора из Telegram и ИИ отправляются после сохранения ответа. В SMS передаётся номер обращения. Переписку и вложения пользователь откроет в кабинете.

## Local-шаблоны событий

Привяжите каждый шаблон отдельным действием с транспортом `local` в контексте владельца услуги. Для оплаты используйте событие успешного платежа, для напоминания — настроенное событие до окончания срока подписки.

**Успешная оплата**

```text
{{ r = user.srv('Sms').send(message = 'vBios: оплата получена. Подробности доступны в кабинете.') }}
```

**Скоро истекает срок**

```text
{{ r = user.srv('Sms').send(message = 'vBios: срок подписки скоро истекает. Проверьте продление в кабинете.') }}
```

SMSC.ru тарифицирует сегменты SMS. Для защиты от повторов приложение ограничивает попытки отправки пятью на один номер за 24 часа. Принятие запроса SMSC.ru подтверждает постановку в очередь. Фактическую доставку проверяйте в отчёте SMSC.ru.

[Документация SMSC.ru](https://smsc.ru/api/)
