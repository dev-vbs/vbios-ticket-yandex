# Настройка страницы /help

В админке SHM откройте «Конфигурация», создайте или измените ключ `apps`. В значение вставьте JSON из `docs/apps-config.example.json`.

`name` — название приложения; `description` — описание; `docs` — ссылка на инструкцию; `download_url` — общая ссылка загрузки; `platforms` — устройства с именем, собственной ссылкой и списком `steps`.

Для нескольких приложений используйте массив объектов:

```json
[
  {"name":"HAPP","description":"Описание HAPP","download_url":"https://happ.info/download","docs":"https://docs.happ.info/main/ru","platforms":[]},
  {"name":"Другое приложение","description":"Ваше описание","platforms":[{"name":"Android","download_url":"https://example.com/download","steps":["Установите приложение.","Добавьте подписку.","Включите подключение."]}]}
]
```

Также поддерживается объект с ключами приложений. Поле `enabled: false` скрывает приложение. Пустой список шагов включает стандартную инструкцию с названием выбранного приложения. Отображается обычный текст, HTML не исполняется. Разрешены только HTTP/HTTPS ссылки. Изменения доступны после обновления страницы, пересборка клиента не нужна. Если apps ещё не настроен, показывается базовая инструкция HAPP. Endpoint `/shm/v1/apps` требует входа и возвращает только разрешённые поля справки.

После установки новой версии:

```bash
cd /opt/shm
docker compose pull client core
docker compose up -d --force-recreate client core
```
