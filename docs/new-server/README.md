# Установка SHM / vBios на новый сервер

Полная актуальная инструкция перенесена в [главный README](../../README.md).

Она включает Docker Compose, базу, HTTPS, администратора, Telegram OIDC, бота и группу поддержки, ИИ, Yandex S3, проверку ключей, обновления и резервные копии.

Файлы этого каталога используются инструкцией:

- [Nginx с HTTPS](nginx-vbios.conf.example).
- [Пример config.ticket](ticket.example.json).
- [Первичная смена пароля администратора](reset-admin.pl).
- [Пошаговая настройка Yandex Cloud](YANDEX-CLOUD-TICKETS.md).

Для уже работающего сервера: [обновление тикетов](../UPGRADE-TICKETS.md) и [совместимость после обновления защиты](../SECURITY-UPGRADE.md). Не повторяйте первичную установку поверх рабочей базы.
