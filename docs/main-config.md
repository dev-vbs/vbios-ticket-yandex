# Настройка стартовой страницы через config.main

Шаблон `docs/main-config-template.txt` выполняется транспортом `local` и создаёт или обновляет конфигурацию `main`. Страница входа получает её через публичный endpoint `/shm/v1/system/main`.

Можно менять название, описание, заголовки, кнопки, шаги, блоки преимуществ, FAQ и названия меню без пересборки клиента. Не добавляйте в `main` токены, пароли, ключи или приватные ссылки: этот раздел публично отдаётся странице входа.

После изменения конфигурации обновите страницу. Перезапуск контейнеров не нужен. Если обновлялись файлы проекта:

```bash
cd /opt/shm
docker compose pull client core
docker compose up -d --force-recreate client core
```
